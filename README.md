# Deposition Contradiction Detector

A React application for comparing two depositions from the same witness and identifying meaningful contradictions between their statements.

## What I Changed

I focused on improving the reliability of the contradiction analysis without adding unnecessary features.

### Server-Side Anthropic Integration

The original application called the Anthropic API directly from the React frontend.

I moved the Anthropic integration to an Express backend so the API key is stored in an environment variable and is never exposed to the browser.

### Structured LLM Responses

Claude is instructed to return structured contradiction data containing:

- The relevant statement from each deposition
- Contradiction type
- A short explanation

The server validates the response before returning it to the frontend.

### Contradiction Classification

Results are classified into three categories:

- **DIRECT** — the statements explicitly conflict and cannot reasonably both be true.
- **INFERENTIAL** — the inconsistency requires reasoning about the same event, time, location, person, or circumstance.
- **FALSE_POSITIVE** — the statements may appear different but can reasonably both be true.

False positives are filtered from the final contradiction results.

### Application-Generated Confidence

Confidence scores are calculated by application logic rather than generated by the LLM.

The current scoring starts with a base score and adjusts it based on:

- Contradiction classification
- Uncertainty language in the witness statements

Examples of uncertainty language include:

- "around"
- "approximately"
- "maybe"
- "I think"
- "I believe"
- "might"
- "possibly"
- "I don't remember"
- "I don't recall"

The final score is constrained between 0 and 100.

This keeps the confidence calculation deterministic and separate from the LLM.

### Improved Classification Prompt

The LLM is asked to consider whether both statements could reasonably be true before classifying them.

This helps prevent ordinary differences in wording, added detail, or approximate testimony from automatically being treated as contradictions.

### UI Improvements

Each displayed contradiction now includes:

- Classification
- Application-generated confidence
- Statement from each deposition
- Explanation of why the statements were flagged

## Running the Project

### 1. Install dependencies

```bash
npm install
```

### 2. Configure the environment

Create a `.env` file in the project root and add your Anthropic API key:

```text
ANTHROPIC_API_KEY=your_api_key_here
```

### 3. Start the application

```bash
npm run dev
```

This starts both the React frontend and Express backend.

Open the Vite URL shown in the terminal, normally:

```text
http://localhost:5173
```

## Testing

I tested the application with:

- Direct contradictions
- Inferential contradictions
- Uncertain or approximate testimony
- False positives where both statements can reasonably be true
- Consistent statements that should not be flagged

## Tradeoffs and Next Steps

I kept the scope focused on improving the core contradiction detection rather than adding unrelated features.

With more time, I would:

- Separate witness certainty from contradiction confidence
- Include surrounding question-and-answer context
- Add automated tests for the confidence-scoring logic
- Evaluate the classifier against a larger labeled set of deposition examples

The application is intended to assist review rather than make a final determination about witness credibility.
